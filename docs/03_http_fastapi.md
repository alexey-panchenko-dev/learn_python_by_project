# HTTP, REST и FastAPI

## Что ты уже знаешь с frontend

HTTP-запрос содержит method, URL, headers и иногда body. Ответ содержит status,
headers и body. JSON — текстовый формат обмена, а не сама база или объект Python.

REST — стиль проектирования вокруг ресурсов и стандартной семантики HTTP. Это не
отдельный протокол. Ресурс `/games/{id}`, а действие хода оформлено вложенным
ресурсом `/games/{id}/moves`.

## Методы и статусы

- GET читает и не должен менять состояние;
- POST создаёт ресурс или выполняет команду;
- PATCH частично изменяет;
- PUT целиком заменяет;
- DELETE удаляет.

Главные статусы: 200 успех, 201 создано, 204 успех без body, 400 плохой запрос,
401 нет подтверждённой личности, 403 личность известна, но нет права, 404 ресурс
не найден, 409 конфликт с текущим состоянием, 422 данные не прошли валидацию.

## Path, query и body

В `/games/{game_id}` id — path parameter. В `?offset=0&limit=20` значения — query
parameters. JSON хода — request body. FastAPI определяет источник по объявлению
параметра и создаёт OpenAPI-схему.

## Pydantic

Pydantic превращает недоверенный JSON в проверенный Python-объект. Schema входа
и schema ответа разделяют внешний контракт и внутреннюю ORM-модель. `Field`
задаёт ограничения, `response_model` фильтрует и документирует ответ.

## Depends и Annotated

`Annotated[AsyncSession, Depends(get_db_session)]` объединяет тип и metadata для
FastAPI. Dependency Injection означает: функция заявляет, что ей нужно, а сборка
и жизненный цикл зависимости находятся снаружи. В тесте настоящую БД поэтому
можно заменить тестовой.

## Swagger/OpenAPI

`/docs` — UI, построенный из OpenAPI. Он полезен для исследования, но не заменяет
тесты. Контракт API доступен также как JSON по `/openapi.json`.

# Краткий словарь

- **API** — договор, как программы взаимодействуют.
- **Endpoint** — сочетание HTTP method и path, обслуживаемое функцией.
- **CRUD** — Create, Read, Update, Delete.
- **Schema/DTO** — форма данных на границе системы.
- **Domain** — предметная область и её правила.
- **Repository** — место, инкапсулирующее доступ к хранилищу.
- **Service** — сценарий использования и координация правил/хранилищ.
- **ORM** — отображение таблиц и запросов на объекты/выражения языка.
- **Migration** — версионированное изменение схемы БД.
- **Dependency Injection** — зависимости предоставляются снаружи.
- **Transaction** — атомарная группа операций БД.
- **Race condition** — результат зависит от неудачного порядка конкурирующих операций.
- **Hash** — одностороннее преобразование для проверки значения.
- **JWT** — подписанный формат claims, часто используемый как access token.
- **Bearer token** — предъявитель токена получает связанные с ним полномочия.
- **Coroutine** — приостанавливаемое вычисление, создаваемое `async def`.
- **Event loop** — планировщик асинхронных задач.
- **I/O** — ожидание сети, диска, БД и других внешних ресурсов.
- **Fixture** — управляемая подготовка окружения теста.
- **Linting** — статический поиск ошибок и нарушений соглашений.
- **Serialization** — преобразование объекта в формат передачи, например JSON.
- **Invariant** — условие, которое обязано сохраняться в определённой точке.
- **Idempotency** — повтор операции имеет тот же эффект, что и один вызов.

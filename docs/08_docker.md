# Docker без магии

Image — неизменяемый шаблон файлов и команды. Container — запущенный экземпляр.
Dockerfile строит image. Compose описывает несколько контейнеров и их связи.
Volume хранит данные вне жизненного цикла контейнера.

## Главные инструкции Dockerfile

- `FROM` выбирает базовый image;
- `WORKDIR` задаёт рабочую папку;
- `COPY` переносит файлы в image;
- `RUN` выполняется во время build и создаёт слой;
- `CMD` задаёт процесс при старте container.

Копирование dependency-файла раньше исходников позволяет Docker повторно
использовать слой установки, пока зависимости не изменились.

## Сеть Compose

Сервисы видят друг друга по именам. Внутри `api` адрес PostgreSQL — `db:5432`,
потому что `localhost` означал бы сам контейнер API. `ports` публикует внутренний
порт на Windows-хост.

`depends_on` задаёт порядок, а healthcheck — готовность. Запущенный процесс БД ещё
не обязательно принимает соединения. Named volume сохраняет каталог PostgreSQL.
